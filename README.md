✨ Aurevyn Beauty

A modern and responsive beauty e-commerce website built with React and Vite.

 🌸 About the Project

Aurevyn Beauty is a modern beauty e-commerce website designed to provide a smooth and elegant online shopping experience.

The website allows users to explore beauty products, view product details, manage their cart and wishlist, and go through a checkout flow.

 🚀 Features

- 🏠 Modern Home Page
- 🛍️ Product Shop
- 🔍 Product Details
- 🛒 Shopping Cart
- ❤️ Wishlist
- 💳 Checkout Page
- 📱 Responsive Design
- 🧭 React Router Navigation
- ✨ Clean and Modern UI

 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Router
- Lucide React
- Git & GitHub
